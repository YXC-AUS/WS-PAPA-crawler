# WS-PAPA-crawler
A playful human pet who crawls with lively monkey-like movement while keeping his familiar glasses, hairstyle, and school uniform.

爬爬（Codex Pet v2）

安装内容：

- pet.json
- spritesheet.webp

将这两个文件放在 Codex 自定义宠物目录的同一个文件夹中：

    %USERPROFILE%\.codex\pets\papa-crawler\

图集为 1536×2288、8列×11行、单格192×208，清单使用 spriteVersionNumber 2。

说明：当前 Codex Pet v2 标准清单和精灵图集不提供“每10秒弹出文字框”的运行时字段，因此“爹”文字气泡未被写入动画帧，也未修改 Codex 主程序。若未来 Codex 提供正式的 Pet 气泡接口，可在不重做角色动画的情况下另行接入。

qa 文件夹包含最终动画接触表、16方向检查图和验证报告。
